# 项目概览

## 名称

- 中文：纹语——苗侗蜡染数字文化交互系统
- 英文：WENYU — Miao-Dong Batik Digital Interactive Heritage System

## 定位

数字文化体验平台：纹样档案、工艺可视化、交互学习、数字共创、作品展览。

## 用户场景

文化爱好者浏览与学习、研学群体工艺导读、设计创作者在浏览器中实验纹样排列并导出 PNG、展览场景大屏或平板演示。

## 当前版本范围

可离线运行的 Web 原型：无 Supabase / AI 密钥依赖。演示数据与 SVG 素材内置在仓库中。

## 竞赛相关

页面不包含参赛身份信息字段；团队与指导教师信息在「关于纹语」中保留为待填写。
